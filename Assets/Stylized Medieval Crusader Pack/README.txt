---

# CHARACTER CUSTOMIZATION

Characters are built using modular parts.

To change the appearance of a character:

* Replace meshes inside the Skinned Mesh Renderer components.
* Helmets, outfits, capes, coifs, belts, ailettes, accessories, hairstyles, and beards can all be swapped this way.
* Weapons and shields can also be exchanged between compatible character prefabs.

Faction colors are controlled through materials.

The models use a stylized color palette workflow based on UV painted 32x32 textures.

This allows different faction and knightly order color schemes to be created while keeping the same modular character system.

---

# ADDING MORE ADDONS

Additional clothing pieces and accessories can easily be added.

To create more addon variations:

* Duplicate an existing addon object.
* Replace the mesh with another compatible mesh.
* Assign the desired material if needed.

The modular system can be used to create additional Crusader units and character combinations beyond the included ready-to-use prefabs.

---

# IMPORTANT NOTE ABOUT RIGGING

This pack uses low poly stylized topology.

Characters are compatible with standard Humanoid workflows and common animation systems such as Mixamo. However, due to the low poly nature of the models, minor deformation artifacts may appear in extreme poses.

If you are new to modular character systems, I highly recommend learning how Skinned Mesh Renderers work in Unity to avoid unnecessary frustration during customization and animation setup.

The horse, bow, and crossbow are also fully rigged.

# HISTORICAL INSPIRATION

The characters, armor, weapons, and equipment in this pack are inspired by historical references from the Crusades and medieval knightly orders.

The pack includes several faction color schemes inspired by Crusader forces and knightly orders, allowing the modular assets to be used to create different armies and unit combinations.

Some elements have been simplified or stylized to maintain the consistent low poly visual style of the pack.

# MATERIALS & TEXTURES

The pack uses a stylized palette-based material workflow.

Most assets use UV painted 32x32 color palette textures to keep the visual style consistent and lightweight.

Included materials and textures cover:

* Faction colors
* Weapons and equipment
* Environment assets
* Metallic surfaces
* Banners and heraldic elements

No normal maps are required for the main stylized assets.
